# Social-Engg-Toolkit

A Python-based educational toolkit for exploring Social Engineering, Open-Source Intelligence (OSINT), digital footprints, and cybersecurity awareness.

## Repository Files

| File | Description |
|---|---|
| `document-finder.py` | Document discovery |
| `email-finder.py` | Email discovery |
| `email-scarper.py` | Email scraping |
| `file-finder.py` | File discovery |
| `hidden_file.py` | Hidden-file discovery |
| `sekit.py` | Security utility |
| `social-media-finder.py` | Social media discovery |
| `subdomain-finder.py` | Subdomain discovery |

## Installation & Usage

**1. Clone the repository:**

```bash
git clone <repository_url>
```

**2. Navigate to the directory:**

```bash
cd Social-Engg-Toolkit
```

**3. Check the files:**

```bash
ls -la
```

**4. Check Python installation:**

```bash
python3 --version
```

**5. Run a script:**

```bash
python3 file_name.py
```

If the script requires a target URL:

```bash
python3 file_name.py https://authorized-domain.com
```

Review each script's source code and dependencies before execution. Commands and arguments may vary.
